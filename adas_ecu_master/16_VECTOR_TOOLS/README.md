## 16.2 CANoe Workflow for ADAS Testing

### Step 1: Create Simulation Environment

```
CANoe Network Configuration:
  CAN channel 1 → Vehicle Bus (BCM, EPS, ESC)
  CAN channel 2 → ADAS Bus (Camera ECU, Radar ECU, ADAS ECU)
  
Node setup:
  Real ECU → connected via Vector VN1630A hardware interface
  Simulated nodes → CAPL simulation nodes (see 16.3)
  DBC → import BCM.dbc, EPS.dbc, ADAS.dbc
```

### Step 2: Configure Signal Mapping

```
In System Variables panel:
  Env.VehicleSpeed    → mapped to CAN signal BCM_VehicleSpeed (0x100, bytes 0-1)
  Env.LaneOffset      → mapped to CAM_LaneData (0x230, bytes 2-3)
  Env.LkaState        → mapped to ADAS_LKA_Cmd (0x300, byte 0)
```

### Step 3: Run Test Sequence

```
vTESTstudio test tree:
  TestSuite_LKA/
    TC_001_Activation_60kph
    TC_002_Override_Detection
    TC_003_Deactivation_Below_60kph

```

## 16.3 CAPL Scripting for ADAS ECU

### Vehicle Speed Ramp (Stimulus)

```capl
// CAPL: Ramp vehicle speed from 0 to 120 km/h over 10 seconds
variables {
    message BCM_Status speed_msg;
    float currentSpeedKph = 0.0;
    msTimer speedRampTimer;
}

on start {
    setTimer(speedRampTimer, 100);  // 100ms interval
}

on timer speedRampTimer {
    if (currentSpeedKph < 120.0) {
        currentSpeedKph += 1.2;   // +1.2 km/h per 100ms = 12 km/h/s ramp
    }
    
    speed_msg.VehicleSpeed = (int)(currentSpeedKph * 10);  // Factor 0.1 → raw
    output(speed_msg);
    setTimer(speedRampTimer, 100);
}
```

### LKA Activation Test

```capl
// CAPL Test: Verify LKA activates when speed >= 60 km/h and lane detected
testcase TC_001_LKA_Activation() {
    // Step 1: Set speed to 50 km/h — LKA should stay STANDBY
    $BCM_Status::VehicleSpeed = 500;   // 500 × 0.1 = 50 km/h
    $CAM_LaneData::LaneQuality = 3;    // HIGH quality
    TestWaitForTimeout(1000);
    
    if ($ADAS_LKA_Cmd::LkaState != 1) {  // 1 = STANDBY
        TestStepFail("TC_001", "LKA should be STANDBY at 50 km/h");
    }
    
    // Step 2: Increase to 65 km/h — LKA should activate (MONITORING)
    $BCM_Status::VehicleSpeed = 650;
    TestWaitForTimeout(1000);
    
    if ($ADAS_LKA_Cmd::LkaState < 1) {
        TestStepFail("TC_001", "LKA should be armed at 65 km/h");
    }
    TestStepPass("TC_001", "LKA activates correctly above 60 km/h");
}
```

### CAN Frame Monitor

```capl
// Monitor LKA command frame and log to trace
on message ADAS_LKA_Cmd {
    write("[LKA] t=%.3f  LkaState=%d  Torque=%.2f Nm  Override=%d",
          timeNow() / 100000.0,
          this.LkaState,
          this.LkaTorqueRequest * 0.01 - 10.0,  // Factor 0.01 offset -10.0
          this.DriverOverride);
}
```

## 16.5 CANape — XCP Calibration for ADAS

### XCP Setup (CAN-based XCP at 500 kbps)

```
CANape connection:
  Transport layer: CAN, 500kbps, XCP CTO ID 0x5E0, DAQ ID 0x5E1
  A2L file: ADAS_ECU_v2.3.a2l   ← generated by compiler/linker
  
Key XCP parameters to calibrate:
  /LKA_Config/Kp                 ← Proportional gain (initial: 0.8)
  /LKA_Config/Ki                 ← Integral gain    (initial: 0.15)  
  /LKA_Config/Kd                 ← Derivative gain  (initial: 0.05)
  /LKA_Config/MaxTorqueNm        ← Max output clamp (initial: 3.0)
  /ACC_Config/TimeGapTarget      ← Following time gap (initial: 1.5s)
  /ACC_Config/MinGapM            ← Minimum absolute gap (initial: 5.0m)

Measurement signals (online DAQ, 10ms):
  LkaState, LkaTorqueRequest, LaneOffset, VehicleSpeed,
  AccState, FollowingGap, AccTorqueRequest
```

### DAQ Rate Configuration

```
DAQ list in CANape:
  Fast list (10ms): LkaTorqueRequest, LaneOffset, HeadingAngle
  Slow list (100ms): LkaState, DriverOverride, SystemStatus
```

## 16.6 CANdb++ DBC Workflow

### Add New Signal to Existing Message

```
1. Open ADAS.dbc in CANdb++
2. Select message ADAS_LKA_Cmd (0x300)
3. Right-click → New Signal
4. Configure:
   Name: LdaWarningLevel
   Length: 3 bits
   Start bit: 13
   Byte order: Intel (little-endian)
   Factor: 1.0
   Offset: 0.0
   Min: 0  Max: 7
   Unit: (none)
   Values: 0=NONE, 1=WARNING, 2=HAPTIC, 3=CRITICAL
5. Add to ADAS_ECU node as TX signal
6. Export DBC
7. Re-import into CANoe project
```
